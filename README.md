# CineGame - Filmes e Jogos

Projeto desenvolvido para a atividade prática de Desenvolvimento Web III.

## Sobre o projeto

O CineGame é um mini portal responsivo sobre filmes e jogos. Ele apresenta categorias simples de filmes e jogos, além de uma seção de perguntas frequentes.

## Tecnologias utilizadas

- HTML5
- CSS3
- Bootstrap 5 via CDN

## Componentes do Bootstrap usados

- Navbar responsiva
- Grid responsivo
- Cards
- Carousel
- Modal
- Accordion
- Badges e botões

## Como abrir

Abra o arquivo `index.html` em um navegador com conexão à internet para carregar o Bootstrap pelo CDN.
